# Projeto Design Profissional - Trilha GitHub Foundations

Este repositorio foi estruturado para consolidar os conhecimentos praticos da trilha GitHub Foundations (Microsoft Learn), integrando conceitos essenciais de versionamento de codigo e colaboracao.

## Objetivo
Demonstrar o dominio completo sobre o ciclo de vida do desenvolvimento de software utilizando o Git e o GitHub, contemplando criacao de repositorios, versionamento, documentacao, criacao de ramos (branches), submissao de Pull Requests e fusoes (Merge).

## Acesso ao Projeto Online
- Aplicacao Lovable: [Visualizar Projeto no Lovable](https://lovable.dev/projects/24e9295d-af8d-4d01-9210-b29e28e1631d)

## Tecnologias e Ferramentas Aplicadas
- Git e GitHub: Controle de versao e hospedagem de codigo.
- Markdown: Linguagem de marcacao para estruturacao da documentacao.
- Python: Linguagem utilizada para a implementacao do script de exemplo do projeto.

## Estrutura do Repositorio
trabalho-fundacoes-github
 README.md          # Documentacao principal do projeto
 media.py           # Script em Python para calculo de notas academicas

## Como Executar o Script
Se quiser testar o codigo em Python incluido neste repositorio:
1. Certifique-se de ter o Python instalado na sua maquina.
2. Execute o arquivo media.py no seu terminal ou editor de codigo favorito:
   python media.py
