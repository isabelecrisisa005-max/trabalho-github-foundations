# Projeto Design Profissional - Trilha GitHub Foundations

Este repositório foi estruturado para consolidar os conhecimentos práticos da trilha GitHub Foundations (Microsoft Learn), integrando conceitos essenciais de versionamento de código e colaboração.

## Objetivo

Demonstrar o domínio completo sobre o ciclo de vida de desenvolvimento de software utilizando o Git e o GitHub, contemplando criação de repositórios, versionamento, documentação, criação de ramos (branches), submissão de Pull Requests e fusões (Merge).

## Tecnologias e Ferramentas Aplicadas

- **Git e GitHub:** Controle de versão e hospedagem de código.
- **Markdown:** Linguagem de marcação para estruturação da documentação.
- **Python:** Linguagem utilizada para a implementação do script de exemplo do projeto.

## Estrutura do Repositório

- `README.md` — Documentação principal do projeto.
- `media.py` — Script em Python para cálculo de notas acadêmicas.
